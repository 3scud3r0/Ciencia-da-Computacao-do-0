# Laboratório de matemática discreta

Quatro ideias viram experimentos executáveis:

- tabela-verdade para lógica proposicional;
- BFS para relações de adjacência em grafos;
- `C(n,k)` para contagem;
- Fibonacci como recorrência.

Use o código para conferir conjecturas, não para substituir provas. Uma execução testa instâncias; uma prova estabelece a propriedade para toda a classe definida.
