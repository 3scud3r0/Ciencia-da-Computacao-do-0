# Sistema de arquivos virtual

Projeto para praticar valores, tipos, funções, classes, recursão, erros e abstração.

`Directory` contém um dicionário de filhos; `File` contém dados. Resolver `/home/user/a.txt` significa percorrer a árvore componente por componente. `walk()` usa recursão para enumerar arquivos.

Execute:

~~~bash
python -m unittest -v
~~~

Depois implemente remoção, `move`, permissões e links simbólicos. O objetivo é perceber como pequenas abstrações compostas formam uma interface maior.
