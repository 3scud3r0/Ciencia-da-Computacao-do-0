## Regra de integração

1. **Catálogo externo:** título, categoria e link para o tutorial original.
2. **Projeto curricular:** quando um projeto for essencial à ementa, criaremos uma implementação própria neste repositório.
3. **Código de terceiros:** somente quando a licença permitir, preservando copyright, atribuição e licença.
4. **Sem cópia em massa:** o objetivo é construir uma obra educacional coerente, não espelhar repositórios alheios.
